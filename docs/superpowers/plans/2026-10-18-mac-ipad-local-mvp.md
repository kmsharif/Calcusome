# Calcusome Mac + iPad Local MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Phase 2 of the product plan: a SwiftUI calculator for macOS and iPad with a decimal engine that passes a shared math spec, and local (unsynced) history with recent-result chips, pin, label and search.

**Architecture:** All logic lives in one Swift package, `CalcCore` (engine, input normalization, SwiftData history store, calculator state model), tested with `swift test` and no Xcode project. A thin SwiftUI multiplatform app (generated by XcodeGen) renders it. `spec/math-cases.json` is the cross-platform contract the Android engine will later run against.

**Tech Stack:** Swift 6.4, SwiftUI, SwiftData, Swift Testing, XcodeGen, Xcode 27. No third-party dependencies.

**Spec:** [Calculator App: Product & Technical Plan](https://claude.ai/code/artifact/ef04c3fc-bdd9-473e-86b1-2009616d36f3) — sections "Platform and engine architecture", "Accounts, sync and history data" (field table), "Phased plan" item 2, "Suggested improvements" rows marked phase 2.

**Roadmap (one plan each, written when the previous one ships):** Phase 1 design foundation (Figma, runs in parallel with this plan) · **Phase 2 this plan** · Phase 3 Supabase accounts + sync · Phase 4 Android (Compose, runs `spec/math-cases.json`) · Phase 5 premium + polish.

## Global Constraints

- Decimal arithmetic only: Swift `Decimal`, never `Double`, anywhere a number is computed or stored.
- Precision: every literal and every intermediate result rounded to **34 significant digits, round half-even** (equals Java `MathContext.DECIMAL128`, which Android will use).
- `|result| >= 1e34` → `overflow` error.
- Canonical expression: ASCII digits, `.` decimal point, no grouping, operators `+ − × ÷ %` and `( )`, minus is U+2212 `−`, no spaces. Example from spec: `500×64`.
- Canonical result: plain notation (no exponent), no trailing fractional zeros, no trailing `.`, ASCII `-` for negatives, never `-0`.
- History fields exactly as the spec table: `id` (UUID, made on device), `userID` (UUID?, nil until Phase 3), `deviceID`, `expression`, `result`, `label?`, `pinned`, `tapeID?`, `createdAt`, `updatedAt`, `deletedAt?`. Every mutation bumps `updatedAt`. Deletes are tombstones (`deletedAt` set), never hard deletes.
- Platforms: macOS 15+, iPadOS 18+ (iPad only, `TARGETED_DEVICE_FAMILY = 2`; iPhone is an open question in the spec — adding it is that one setting).
- Bundle ID placeholder `com.calcusome.app` — replace before TestFlight.
- Accessibility every phase: every key has a VoiceOver label; motion respects Reduce Motion.

## Review Focus

1. **`=` on an incomplete expression** (`5+`, `(2`) → nothing saved, input kept, inline "Incomplete" hint; never a crash. Test in Task 4.
2. **Pasted text in the person's locale** (`1.234,5` in de_DE, `৫০০×৬৪` in bn_BD, `12*3/4` anywhere) → parsed, not rejected. Spec cases in Task 2.
3. **Pressing `=` twice** → one history entry, not two. Test in Task 4.
4. **Long results** (`1÷3`, 34 digits) → display shrinks to fit (`minimumScaleFactor`), full value kept in history. Checked in Task 5.
5. **Deleted entries** never reappear in chips, list or search. Test in Task 3.

- [ ] **Step 4: Write `SpecTests.swift`**: a parameterized `@Test(arguments: cases)` that decodes the file and, for cases without `locale`, asserts `DecimalRounding.canonical(try Engine.evaluate(input)) == result`, or that `Engine.evaluate(input)` throws `CalcError(rawValue: error)`. Test name includes the case `id`.

- [ ] **Step 5: Run** `swift test --package-path apple/CalcCore` → FAIL (`Engine` not defined).

- [ ] **Step 6: Implement `DecimalRounding`**. `round34`: compute the number's decimal exponent, then `NSDecimalRound` with scale `34 − (integer digits)` and mode `.bankers`. `canonical`: `Decimal.description` (plain notation), map `-0` to `0`.

- [ ] **Step 7: Implement `Engine.evaluate`** as recursive descent over the canonical string. The grammar pins percent semantics:

```
expr    := term (('+' | '−') term)*     right term is percent-only → a ± a×p/100
term    := factor (('×' | '÷') factor)* 
factor  := '−' factor | primary '%'?    p% = p/100
primary := number | '(' expr ')'
number  := digit+ ('.' digit+)?
```

`parseTerm` returns `(value: Decimal, isPercent: Bool)`; `isPercent` is true only when the term is a single factor ending in `%`. Round each literal and each operation result with `round34`; throw `.overflow` when `abs >= 1e34`, `.divideByZero` on a zero divisor, `.syntax` on anything unconsumed or missing.

- [ ] **Step 8: Run** `swift test --package-path apple/CalcCore` → all 29 spec cases PASS.

- [ ] **Step 9: Add `.github/workflows/apple.yml`**: on push/PR, `runs-on: macos-latest`, `swift test --package-path apple/CalcCore`.

- [ ] **Step 10: Commit** `feat: decimal engine passing shared math spec`

### Task 3: SwiftData history store

**Files:**
- Create: `Sources/CalcCore/HistoryEntry.swift`, `HistoryStore.swift`, `DeviceID.swift`
- Test: `Tests/CalcCoreTests/HistoryStoreTests.swift`

**Interfaces:**
- Produces:
  - `@Model public final class HistoryEntry` with the fields in Global Constraints (`@Attribute(.unique) id`).
  - `public enum DeviceID { public static func current(_ defaults: UserDefaults = .standard) -> String }` — UUID string created once under key `deviceID`.
  - ```swift
    @MainActor public final class HistoryStore {
      public init(container: ModelContainer, deviceID: String, now: @escaping () -> Date = Date.init)
      public static func inMemory(deviceID: String = "test", now: @escaping () -> Date = Date.init) throws -> HistoryStore
      @discardableResult public func add(expression: String, result: String) throws -> HistoryEntry
      public func recent(limit: Int) throws -> [HistoryEntry]   // live only, newest createdAt first
      public func all() throws -> [HistoryEntry]                // live only, pinned first, then newest
      public func search(_ text: String) throws -> [HistoryEntry] // live only, case-insensitive on label or expression
      public func setPinned(_ entry: HistoryEntry, _ pinned: Bool) throws
      public func setLabel(_ entry: HistoryEntry, _ label: String?) throws  // "" stored as nil
      public func delete(_ entry: HistoryEntry) throws          // tombstone
    }
    ```

- [ ] **Step 1: Write tests** (inject a `now` closure backed by a mutable clock):
  - `addSetsFields`: `add("500×64","32000")` → `deviceID == "test"`, `userID == nil`, `pinned == false`, `createdAt == updatedAt == clock`.
  - `recentNewestFirst`: three adds at t1<t2<t3, `recent(limit: 2).map(\.result) == [r3, r2]`.
  - `pinnedFirst`: pin the oldest → `all().first` is it.
  - `searchMatchesLabelAndExpression`: label "Rent split" found by `"rent"`; expression `500×64` found by `"500"`.
  - `mutationsBumpUpdatedAt`: advance clock, `setLabel` → `updatedAt == new clock`, `createdAt` unchanged. Same for `setPinned`, `delete`.
  - `deleteIsTombstone` (Review Focus 5): after `delete`, entry absent from `recent`, `all`, `search`; a raw `FetchDescriptor<HistoryEntry>()` still returns it with `deletedAt != nil`.
  - `deviceIDStable`: two calls on one `UserDefaults(suiteName:)` return the same value.

- [ ] **Step 2: Run** → FAIL. **Step 3: Implement.** Filter live rows with `#Predicate { $0.deletedAt == nil }`. **Step 4: Run** → PASS.

- [ ] **Step 5: Commit** `feat: local history store with tombstone deletes`

### Task 4: Calculator state model

**Files:**
- Create: `Sources/CalcCore/CalculatorModel.swift`
- Test: `Tests/CalcCoreTests/CalculatorModelTests.swift`

**Interfaces:**
- Consumes: `Engine`, `DecimalRounding`, `InputNormalizer`, `HistoryStore`
- Produces:
  ```swift
  public enum Key: Hashable, Sendable { case digit(Int), decimal, add, subtract, multiply, divide, percent, openParen, closeParen, negate, backspace, clear, equals }
  @MainActor @Observable public final class CalculatorModel {
    public init(store: HistoryStore, locale: Locale = .current)
    public private(set) var expression: String   // canonical, what's been typed
    public private(set) var result: String?      // canonical, set after a successful "="
    public private(set) var error: CalcError?
    public private(set) var recent: [HistoryEntry] // up to 8, for chips
    public func press(_ key: Key)
    public func paste(_ text: String)            // normalize, replace expression
    public func reuse(_ entry: HistoryEntry)     // chip tap: append entry.result
  }
  ```

- [ ] **Step 1: Write tests** against `HistoryStore.inMemory()`:
  - `typingBuildsCanonical`: press 1,2,×,3 → `expression == "12×3"`.
  - `equalsSavesOnce` (Review Focus 3): 2,+,2,=,= → `result == "4"`, store `all().count == 1`.
  - `incompleteDoesNothing` (Review Focus 1): 5,+,= → `error == .syntax`, `expression == "5+"`, store empty.
  - `divideByZeroNotSaved`: 1,÷,0,= → `error == .divideByZero`, store empty.
  - `typingAfterResultStartsFresh`: 2,+,2,=, then 5 → `expression == "5"`; but 2,+,2,=, then + → `expression == "4+"` (continue from result).
  - `negateTogglesLastNumber`: 5,negate → `"−5"`; again → `"5"`.
  - `backspaceAndClear`: 1,2,backspace → `"1"`; clear → `""`, `result == nil`, `error == nil`.
  - `pasteNormalizes`: `paste("1.234,5+1")` with de_DE → `expression == "1234.5+1"`.
  - `reuseAppendsResult`: after 2,+,2,= then +, tap the entry → `expression == "4+4"`.
  - `recentRefreshes`: after `=`, `recent.first?.result == "4"`.

- [ ] **Step 2: Run** → FAIL. **Step 3: Implement.** Keep a private `justEvaluated` flag for the fresh-start rule; skip saving when the evaluated expression equals the last saved one in this session. **Step 4: Run** → PASS.

- [ ] **Step 5: Commit** `feat: calculator state model`
